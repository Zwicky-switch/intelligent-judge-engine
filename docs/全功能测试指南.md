# 智评 · Insight —— 小白全功能测试指南(照着点就能测完)

> 面向完全不懂代码的同学。不需要知道任何技术细节,按顺序点 6 个「站点」,就能把 8 种题型、图片/录音/视频识别、5 种角色、双评与仲裁、能力诊断全部测一遍。
> 总时长约 40~60 分钟。建议把本文档和浏览器窗口左右并排。

---

## 0. 先记住这张「地图」

系统里有 6 个账号,每个账号在界面里能干的事不一样:

| 账号(用户名 / 密码) | 是什么人 | 主要在哪儿 | 你要测什么 |
|---|---|---|---|
| `admin / admin123` | 教务管理员 | 质量看板、审计 | 全局数据、看板指标 |
| `prop_teacher / teacher123` | 命题陈老师 | 题库、发布 | 出题、双人复核发布 |
| `grader / teacher123` | 阅卷张老师 | 复核中心 | 复核、双评第 1 评 |
| `grader2 / teacher123` | 阅卷刘老师(阅卷二) | 复核中心 | 双评第 2 评 |
| `student_li / stu123` | 学生李雪(强) | 我的成绩 / 自主练习 / 诊断报告 | 答题、查分、诊断 |
| `student_wang / stu123` | 学生王哲(中) | 同上 | (给双评题准备作答) |

测试思路一句话:**每个角色用自己的账号进去,干自己该干的那件事;同一件事用两个不同角色接力,就能验证"协作"功能(双评要两位老师、发布要两人复核)。**

## 1. 开始前的准备(2 分钟)

1. 确认服务已启动:
   - 如果开发同学已经把服务跑起来了,直接打开浏览器访问 **http://127.0.0.1:5173**。
   - 如果没有启动:双击项目根目录 `scripts\start_all.bat`,等它自动打开浏览器(第一次可能要几十秒到几分钟初始化演示数据,耐心等,**期间不要关黑窗口**)。
2. 登录页有常用账号的快捷按钮,点一下就能登录,不用手动输。
3. 桌面准备好一个 mp3/wav 录音文件、一个视频文件、一张图片(后面第 4 站会用到):
   - **图片**:打开「记事本」,粘贴一段话(建议粘贴本文档第 4 站给的主观题样文),再按 `Win+Shift+S` 把记事本截图存成一个 png → 这就是"手写图片作答"。
   - **录音**:手机/电脑录一段你自己念的话(10~40 秒即可)。
   - **视频**:手机横屏录 20~60 秒,念一段实验流程(念到下面几个词就行:**打点计时器、重物、电源、通电、释放、机械能守恒、误差**)。

> ⚠️ 页面需要联网才能用"图片识别(OCR)"。如果断网,图片识别会提示未配置或失败,不影响其它功能测试。

## 2. 第 1 站:管理员看全局(约 5 分钟)

**目的**:确认系统是活的、有真实数据、有指标。

1. 用 `admin / admin123` 登录。
2. 左侧点 **「质量看板」**:
   - 应看到一排数字:答卷总数、自动放行数、待复核数、已终审数;
   - 下方有 **存量分数重放一致率(客观题守门，应为 100%)、engine↔教师一致率、延迟、分数段分布、班级六域画像** 等卡片。
3. 点左侧 **「审计日志」**:能看到一条条操作记录(谁、几点、做了什么),并且**没有删除按钮**(全程留痕,不可删)。
4. 点页面顶部 **技术铭牌 / 引擎导览**(侧边栏"引擎技术导览"页):看引擎版本 `insight-judge-v0.1`,知道系统是"本地内置引擎"在判题。
5. **记住几个数**(比如:自动放行 32、待复核 10),第 6 站回来对比数字有没有变。

---

## 3. 第 2 站:命题老师出题与"双人复核"发布(约 8 分钟)

**目的**:验证 8 种题型都能被命题、量规/答案可见、发布要走两道关。

1. 退出,换 `prop_teacher / teacher123` 登录。
2. 点 **「题库」**:列表里应能翻到这些题(看看它们的类型标签对不对):
   - 单选:001(矢量)、002(匀加速)、003(牛顿第二定律)、009(保守力)
   - 判断:004(作用力反作用力) ・ 多选:007(接触力)、010(机械能守恒)
   - 填空:005(F=ma…) ・ 数值:006(加速度)、008(动能) ・ 公式:070(a=F/m)
   - 主观:020(斜面拉物体)、050(自由落体动能定理)、060(跳伞草稿)
   - 口语:030(讲牛顿第二定律) ・ 实操视频:040(打点计时器实验)
3. 随便点开一题(如 020),看它的 **得分点量规**(P1/P2/P3 各几分、每个点看什么关键词)和 **参考答案**——这是系统判分的依据。
4. 点开 **060(跳伞题)**:它现在还是**草稿(未发布)**。
   - 点 **发布**:系统会提示这道题设了「双人复核」,需要 **2 个不同账号** 确认。
   - 试试**自己再确认一次**:应被拒绝(不能自己给自己复核) → 这就是"发布质量门"。
   - 退出,用 `grader` 登录(阅卷老师也能做发布复核),在提示处找到这条待复核发布并**确认**。
   - 回到 `prop_teacher`,看到 060 已变成"已发布",并可在「版本历史」里看到本次变更记录/与旧版对比。
5. (可选加分)在 060 编辑页点 **量规模板** 下拉:有两个模板可「套用」到新题。

---

## 4. 第 3 站:学生现做现判(约 15 分钟,核心!)

**目的**:把 8 种题型**亲手提交一遍**,看自动判分、证据、转人工这些表现。

用 `student_li / stu123`(李雪)登录,先点 **「我的成绩」** 看已有试卷(会看到客观题已即时出分、主观题得分点高亮、口语题四层表现),再从 **「自主练习」/作答区** 提交新作答:

> 每种题都能测 **两遍**:第一遍答对 → 看即时满分;第二遍故意答错/乱答 → 看扣分有理由、或转人工。**空着提交 → 必须转人工复核,不能默默给 0 分**(这是本系统的硬规则,重点演示)。

| 题型(题号) | 第 1 遍:答对的样子(复制即可) | 第 2 遍:故意答错 | 期待看到 |
|---|---|---|---|
| 单选 001 | 选 **A** | 选 **C** | 满分 2 / 0 分并给出"答错"理由 |
| 判断 004 | 选 **错(×/F)** | 选 对(√/T) | 满分 / 0 分 |
| 多选 007 | 选 **A、B** | 只选 A 或选 A、C | 部分给分(3 分里得部分) |
| 填空 005 | 填:`ma \| 牛顿 \| 惯性`(用 | 或 , 分隔三个空) | 把第 3 空写成"匀速" | 3 空按空计分,部分对得部分分 |
| 数值 006 | 填:`5 m/s^2` | 填 `5 N`(单位错)或 `9` | 数值对但单位错 → 0 分(量纲守护) |
| 数值 008 | 填:`50 J` | 填 `50`(漏单位) | 漏单位给部分分(单位占 0.3) |
| 公式 070 | 填:`F/m` | 填 `m/F` | 秒级确定性判分:对/错,还能识别等价写法 |
| 主观 020 | 粘贴**样文 A**(见文末) | 只粘贴**样文 B** 那句短的 | 得分点高亮 + 证据原文标色;完整答 → 自动放行;只写一句 → 转教师复核 |
| 口语 030 | 粘贴**样文 C**(文本誊抄),可选再「选择录音」上传你录的音频 | 粘贴"如图,忘了"(样文 D) | 内容/表达给分;**流畅/发音标"无数据"**(还没接发音评测,如实显示);录音会作为证据留存 |
| 实操视频 040 | 点「上传过程视频」选你录的实验视频 | — | 音轨被自动转写 → 提到"打点计时器/重物/电源"等词的步骤自动给分;动作类步骤标"证据不足",整卷**转人工复核** |
| 图片 OCR(主观 020 上) | 点「上传手写图片」选你截的图 | — | 等 2~5 秒,OCR 出文字并**自动判分**;原图在得分证据里可点开查看 |

**第 3 站做完**你手里应该新增:一批"即时出分"的客观卷、一两个"转人工"的主观/视频卷。

## 5. 第 4 站:阅卷老师复核(约 8 分钟)

**目的**:把"待人工复核"的卷子人工收尾,并给双评题做第 1 评。

1. 退出,用 `grader / teacher123`(张老师)登录,点 **「复核中心」**。
2. 上方会分几个队列:**待复核(强制/抽样)**、**双评待第 1 评**、双评待第 2 评、双评待仲裁。
   - 打开一个你刚才"只写一句"的主观题(或弱生的卷):看到**逐得分点的证据高亮**(系统把学生原文里命中的关键词标出来了)。
   - 用按钮 **「接受模型分」**(也可以试试 **教师改分**、或 **退回模型重评**)→ 该卷从队列消失、进入已终审。
3. 找到 **双评题 050(自由落体,王哲作答)**,此时它处于「待第 1 评」。
   - 给它打一个独立分,例如 **5 分**,点「第 1 评独立分」提交。
   - 系统会显示:本卷已完成您的独立评阅,**需要另一位教师**做第 2 评(自己不能评第二次——防止同一个人假装双评)。
4. (选看)试试把 050 再评一次 → 应被系统拦截并提示"需另一位教师独立完成"。

---

## 6. 第 5 站:第二位数师 + 双评仲裁(约 8 分钟)

**目的**:验证"两位老师背靠背打分"和"分歧太大就请第三人仲裁"。

1. 退出,用 `grader2 / teacher123`(刘老师)登录,进「复核中心」。
2. 找到刚才张老师评过第 1 评的 050(此时是「待第 2 评」)。
   - 给它第 2 评 **6 分**(和第 1 评的 5 分只差 1,在容差内)→ 提交。
   - 系统应自动完成:分差 ≤ 容差,**终审取平均 5.5 分**,状态变「双评完成」→ 双评取均值逻辑演示成功。
3. **演示"超差仲裁"(分歧大)**——需要一个双方打分差很多的双评卷:
   - (第 4 站若按上表给了 5/6 则已走完;为了看仲裁,请张老师或刘老师另开一个流程:用 `prop_teacher` 在题库**新建一道主观题**,在"评分策略"里勾选 **双评**,发布它;然后用 `student_wang` 在练习里随便提交一句;张老师评 **3 分**、刘老师评 **6 分**——分差 3 > 容差)
   - 提交后队列出现 **「双评待仲裁(超容差)」**。
   - 换第三个不同账号 **`admin`** 登录 → 在复核中心进入「待仲裁」→ 用「仲裁终审」给一个终分(如 5)→ 双评完成,终审记录写明"分差超容差,第三位教师仲裁"。
   - (若不想新建题:第 4/5 站第一次只做"5 分/6 分一致"分支即可,仲裁分支略过,不扣分。)

## 7. 第 6 站:回到学生查分 + 看诊断报告(约 8 分钟)

1. 退出,用 `student_li` 再登录,点 **「我的成绩」**:
   - 刷新后看到:你新提交的客观题已即时出分、主观/视频卷状态变成"已终审"或仍"待复核";050 若你评了,能看到终审 5.5 与"双评取均值"说明。
   - 展开任一分,点证据里的 **图片/录音/视频**,能直接回放/查看(媒体回放)。
2. 点 **「能力诊断报告」**:
   - 看到 **六域雷达图**、**知识热力图**、**60 维能力全景**、**短板 Top3**、**学习建议**。
   - 换 `student_wang`、`student_zhao` 登录看同一页 → 三人的雷达和短板应明显不同(强/中/弱三档)。
3. 最后回到 `admin` 看板,对比第 1 站记下的数字:
   - 待复核数应下降、已终审数上升;若你完成了双评,看板里 **「双评教师一致率」应出现数字(pairs ≥ 1)**。

## 附:三份可直接粘贴的样文

**样文 A(主观题 020 完整作答——系统判定高分):**
> 受力分析:物体受重力 G=mg=20N 竖直向下,支持力 N 竖直向上,拉力 F=25N 与水平成 37° 斜向上,滑动摩擦力 f 水平向后。把拉力正交分解:Fcos37°=20N,Fsin37°=15N。竖直方向平衡 N+Fsin37°=mg,得 N=20-15=5N;f=μN=0.2×5=1N。水平方向由牛顿第二定律 Fcos37°-f=ma,即 20-1=2a,解得 a=9.5m/s²,方向水平向右。

**样文 B(只写一句——用于演示"转人工复核"):**
> 这题用牛顿第二定律做,直接 F=ma,a=25/2=12.5。

**样文 C(口语题 030 转写稿):**
> 牛顿第二定律说的是,物体的加速度大小和它受到的合外力成正比,和它的质量成反比,加速度方向与合外力方向相同,公式是 F=ma。举个例子,坐公交车时司机突然急刹车,车上的人身体会往前倾,这就是惯性;刹车时地面给车很大的摩擦力让车产生向后的加速度,车才停下来。

## 附:遇到问题快速对照

| 现象 | 原因 / 处理 |
|---|---|
| 浏览器打开是白屏 | 一定是直接双击了 `frontend/index.html`,要用网址 **http://127.0.0.1:5173** 访问 |
| 端口被占用启动失败 | 说明之前有个服务没关;把旧的黑色命令窗口全关掉再双击 `start_all.bat` |
| 图片识别提示未配置/失败 | OCR 走联网视觉模型,检查网络;或请开发同学装离线 OCR(`python -m pip install rapidocr-onnxruntime`) |

| 数字和文档对不上 | 说明有同学在你之前也测过;无妨,流程照着走即可。想从零重置:让开发同学运行 `python -m app.seeds.demo --reset` 后重启 |
