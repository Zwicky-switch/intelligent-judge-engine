## 三、模型选择说明（含实测依据）

### 3.1 双模型分工

| 任务 | 模型 | 选择依据（实测） |
|---|---|---|
| 主观题判点复核 + 中文评语 | **智谱 glm-4.7** | 用户指定；纯文本调用 HTTP 200 跑通，文本质量满足判点复核与评语生成 |
| 图片 OCR（手写/截图转文字） | **智谱 glm-4v-flash** | **glm-4.7 不支持图片输入**（实测返回错误 1210：content.type 仅接受 text），故 OCR 必须用视觉模型；glm-4v-flash 免费额度、图片输入 HTTP 200 并正确识别手写解题过程 |
| 本地离线兜底 | **RapidOCR**（rapidocr-onnxruntime 1.4.4） | 未配置 Key 或云端调用失败时自动回退，不依赖外网 |
| 内置确定性引擎 | `builtin` | 未配置 Key 时全题型离线可跑（客观/公式 100% 确定性） |

### 3.2 模型选择的经验

1. **"最新模型"≠"全能力"**：glm-4.7 是纯文本模型，视觉任务必须用视觉模型，不能凭模型名推断能力边界——用真实调用验证（本项目实测暴露）。
2. **降级链完整**：大模型 → 本地引擎 → RapidOCR，任一环节失败不阻塞判分，只是精度/质量降级，保证系统可用性。
3. **Key 不进代码**：provider/base_url/model 进配置，Key 只进 `.env`（gitignore）或部署环境变量。

## 四、算法实现要点（核心引擎）

| 模块 | 算法 | 实现位置 | 要点 |
|---|---|---|---|
| 主观题判分 | **语义槽覆盖度 v2** | `backend/app/parsers/text.py::slot_coverage_ratio` + `engines/subjective.py::_judge_point` | 槽=同义变体分组，命中任一即槽覆盖；覆盖度=命中槽数/总槽数；消除"同义变体膨胀分母"缺陷（v1 字符覆盖率 11.1% → v2 100%，平均分差 2.56 → 0.33） |
| 主观题算分 | 量规权重确定性结算 | `engines/subjective.py::grade_subjective` | 满足=满分 / 部分=0.5×分 / 不满足=0；罚分仅采纳 `scoring_policy.penalties` 显式项并夹取上限；大模型只复核判点不绕过 | 
| 置信度路由 | 三级复核路由 | `subjective.py`（review_level） | 空答/低质/引图作答 → 强制复核；置信度 < 阈值 → 抽样复核；客观题自动放行；不静默给 0 分 |
| 公式题 | 符号等价 + 数值抽样兜底 | `engines/symbolic.py` | sympy 化简判 `==` 优先；离线用固定种子 Random(2026) 采样 N 点（4×变量数+4），相对误差 <1e-6，一点不符即证伪；AST 白名单安全求值（封禁 `__builtins__`、属性访问、超大指数） |
| 客观题 | 确定性匹配 | `engines/objective.py` + `engines/numeric.py` | 多选 full/partial、填空顺序敏感+别名、数值单位族换算+容差+有效数字；47 例金标准全绿 |
| 口语四层 | 内容/表达/流畅/发音 | `engines/spoken.py` | 流畅层接 faster-whisper 词级时间戳真算（语速/停顿）；发音层未接入音素对齐标 nodata、权重自动重归一 |
| 图片 OCR | 视觉模型 → 文本 → 主观引擎 | `parsers/image_ocr.py` | 视觉模型优先 + RapidOCR 兜底；低质量识别经质量门控转人工 |
| 视频（基础版） | 音轨转写 + 步骤关键词 | `engines/video_stub.py` | faster-whisper 直转音轨（PyAV 无需 ffmpeg）；未配关键词步骤标"证据不足"不扣分、整卷转人工 |
| 能力诊断 | Q 矩阵 + BKT + IRT + 画像 | `diagnostics/` | 60 维能力全景；BKT 时序拟合；IRT θ 启发式参数（大样本标定待做）；`profile_match` 作答-画像匹配度 |
| WER/CER 评估 | Levenshtein 编辑距离 | `scripts/asr_eval/asr_wer_eval.py`、`scripts/ocr_eval/eval_ocr_cer.py` | 字符级（CER）+ jieba 词级（WER）；真值模板与"AI 校对真值"方案见 README |

### 5.1 真人评测替代方案（无人力时如何量化验证）

> 真实教师盲评/人工听写尚未到位时，以下三套替代方案已落地并量化，**可作为真实评测前的基线**；正式交付仍需真实教师/人工抽检校准（见各方案"局限"）。

| 替代项 | 方案 | 方法 | 结果 | 局限 |
|---|---|---|---|---|
| 教师盲评 → **模拟教师二审** | 标准答案 + 关键字对照法 | 3 道基础低开放性题（牛顿第二定律/惯性/动能定理）× 强/中/弱三档 = **9 份答卷**；引擎判分 vs 关键字对照模拟教师二审（阈值略宽模拟人工宽松度） | v1 88.9% → **v2 语义槽优化后 100%（9/9）**，平均分差 0.33 | 仅适用基础低开放性题；非真实教师盲评；高开放性题仍需真实教师；脚本 `scripts/teacher_sim/` |
| ASR 人工真值 → **"AI 充当人力"代理真值** | 交叉转写 + AI 语境校对 | 保留学生原口语句式，仅修正同音字/术语，建立 5 段真实素材逐字真值 | **WER 16.95% / CER 7.29%** | 代理真值非真人听写；正式交付需人工抽检 ≥10% 校准；公式符号误识别（EK→1K）已实证影响判分；真值模板 `scripts/asr_eval/` |
| OCR 人工真值 → **逐字校对** | 人工逐字转写 4 张真实手写图 | 对照学生原图建立逐字真值，计算字符错误率 | 加权 **CER 24.06%**（正文良好、公式域符号误差为主） | 样本量小（4 张）；公式域可经提示词优化/公式裁剪继续降；真值 `scripts/ocr_eval/ground_truth/` |

**统一口径**：三套方案均为"替代真值/替代评分"，数字只代表对应替代基准下的指标，**不替代**真实教师盲评与人工听写的正式结论；真实评测到位后需重算并以真实结果为准。
