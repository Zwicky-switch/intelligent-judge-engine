## 二、模块技术方案说明

### 2.1 评阅处理闭环

```
提交(文本/图片/音频/视频)
  → ①答案质量门控(空答/质量不过关不静默判分)
  → ②题型路由到对应引擎
  → ③引擎产出 EngineOutcome {总分, 逐得分点结果, 证据 hits, 置信度, 复核档位}
  → ④落库 Score + Evidence(作答原文字符区间/关键词片段/媒体侧车)
  → ⑤置信度路由: 自动放行 / 抽样复核 / 强制复核
  → ⑥教师复核(接受/改分/仲裁/退回模型) · 双评题两位教师背靠背 → 超差第三方仲裁
  → ⑦能力诊断(60 维 Q 矩阵 + BKT)与个性化建议
```

### 2.2 支持题型范围与各题型的评阅算法/模型

| 题型 | 评阅方式 | 实现要点 |
|---|---|---|
| 单选 / 判断 | 确定性字符匹配(别名归一、中英文对/错/正确等) | 答对满分，答错/空答 0 分且**必须带可解释 reason**，不静默 |
| 多选 | 确定性集合比较 | `scoring_mode=full` 全对才得分；`partial` 支持部分给分、错一项抵消 |
| 填空 | 确定性按空比对 | 支持顺序敏感/顺序无关、空值别名表、空白归一 |
| 数值 | 确定性数值判定 | **单位族换算**(m/s² 与 中文单位互认)、绝对容差/相对容差、**有效数字校验**、量纲不符(数值对但单位错)判 0 |
| 文本主观 | 本地证据优先启发式；可选升级大模型协同 | 关键词覆盖率 `coverage_ratio` 分档(满足/部分/不满足)；逐得分点召回原文证据；模型**只复核判点、不绕过量规给分**，分值按量规权重确定性结算并二次夹取；罚分建议被夹取在策略上限内 |
| 公式 | 确定性等价判定 | 符号等价优先 `sympy`；无该依赖时变量域**数值抽样**(种子 `Random(2026)`、相对误差 <1e-6、AST 安全求值)兜底；**幂等、沙箱无代码执行** |
| 口语 | 内容 / 表达 / 流畅 / 发音 四层 | 内容+表达按量规判点；流畅层已接 faster-whisper 词级时间戳**真算**(口语/视频音轨均端到端实测)；发音层为预留评测源，未接入音素对齐前统一标 nodata → 未得分维度权重自动重归一 |
| 实操视频(基础版) | 音轨转写 + 步骤量规关键词 | faster-whisper 直转视频音轨(PyAV，无需 ffmpeg)；**配置了关键词的步骤**自动判内容覆盖分；未配关键词的动作/时序步骤标「证据不足」不扣分、整卷转人工(强制复核兜底) |
| 图片作答(OCR) | 视觉模型 → 文本 → 复用主观判分 | 视觉多模态模型提取手写/截图文字后走文本判分引擎；原图留存证据。独立配置 `OCR_LLM_*`(支持智谱 glm-4v-flash / 通义 qwen-vl-plus)；**未配置时回退本地 RapidOCR(离线兜底)** |

**评阅约束原则(贯穿全系统)**：大模型/引擎不直接加分区，只给判点意见/罚分建议/评语；终分一律由量规权重确定性结算；所有记录不可删除、写入审计日志，保证可回溯。

### 2.3 能力诊断维度设计

- **Q 矩阵**：题目/知识点显式绑定到能力维度，课程级 6 大能力域 × 10 二级维度 = 60 维全景(支持按课程停用维度)。
- **掌握度**：`compute_mastery` 输出能力分与观测数、置信度；未观测维度如实上报(不臆造)。
- **时序掌握**：BKT 在已观测作答序列上拟合，输出知识节点掌握时序。
- **画像匹配**：`profile_match` 反映学生作答模式与画像的匹配度。
- **报告出口**(学生端)：六域雷达图 + 知识热力图 + 60 维能力全景 + 短板 Top3 + 先修/微课/练习建议 + 画像-作答匹配度 + θ 值。

## 七、风险点与后续规划(如实上报)

3. **口语发音层**：音素级评测源未接入，如实标 nodata、不产生无效评分；流畅层已接 faster-whisper 词级时间戳真算(口语/视频音轨均实测)。
4. **实操视频为"基础版"**：仅内容覆盖维自动判分，动作/时序步骤由教师人工补齐(强制复核兜底)，姿态识别列入后续。
5. **判分模型当前为本地内置**(未配置 `GRADE_LLM_*` Key)：功能完整可演示；接入外部大模型可提升主观题评语质量与判点召回，属「配置即升级」。
6. **后续规划**：生产部署加固(多 worker + 幂等锁)、并发批卷、REST 文档化开放接口、真实题库 IRT/BKT 参数标定。
