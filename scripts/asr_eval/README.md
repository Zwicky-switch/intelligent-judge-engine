# ASR 转写验证与 WER/CER 评估说明

> 更新：2026-09-13
> 场景：口语作答（录音）+ 实操视频（音轨）→ faster-whisper 转写 → 语义槽引擎判分

---

## 一、评估结论（2026-09-13 实测）

### 1.1 转写质量（faster-whisper-small，真实学生素材 5 段）

| 素材 | 时长 | 转写字数 | WER | CER |
|---|---|---|---|---|
| 同学1 录音1（牛顿第三定律） | 12.0s | 48 | 11.11% | 6.38% |
| 同学1 录音2（动能） | 17.4s | 71 | 31.71% | 7.04% |
| 同学2 录音3（牛顿第三定律） | 23.6s | 94 | 16.98% | 6.38% |
| 同学2 录音4（动能） | 29.9s | 136 | 10.84% | 5.80% |
| 题5 视频（弹簧测力计实验） | 37.3s | 120 | 14.08% | 10.83% |
| **平均** | | | **16.95%** | **7.29%** |

- **CER 7.29%**：识别质量良好，正文语义完整，判分可用
- **WER 16.95%**：词级错误主要集中在**同音字/术语误识别**（见下）
- 真值口径：保留学生口述原词序句式，仅修正同音字/术语错误（避免"标准书面语"口径高估错误率）

### 1.2 典型 ASR 误识别（同音字/公式符号）

| 正确 | ASR 识别 | 类别 |
|---|---|---|
| 测力计 | 侧力剂 | 物理术语同音 |
| 读数 | 读书 | 同音字 |
| 刻度 | 克度 | 同音字 |
| 调试 | 调室 | 同音字 |
| 船桨 | 船讲 | 同音字 |
| 推墙 | 推强 | 同音字 |
| 瞬时速度 | 顺时速度 | 同音字 |
| 破坏力 | 拋坏力 | 同音字 |
| 动能更大 | 都能更大 | 同音+组词 |
| EK | 1K | **公式符号** |
| 二分之一 | 1⁴ | **公式符号** |
| MV方 | M为方 | **公式符号** |
| 小轿车 | 小较车 | 同音字 |

**规律**：正文文字误识别以同音字为主（语义槽量规可通过补充变体吸收）；**公式/符号误识别最严重**（EK→1K、二分之一→1⁴），直接影响公式类得分点。

### 1.3 对判分的影响（关键实证）

以录音4（动能）为例，引擎语义槽判分：

| 输入 | 得分 | 差异 |
|---|---|---|
| ASR 原文（1K、1⁴） | **5.0/6** | P2"公式形式"槽未命中 |
| 修正真值（EK、二分之一） | **6.0/6** | 全中 |

**结论**：ASR 公式符号误识别会丢失得分点。对策：
1. 语音题量规的公式槽补充 ASR 易错变体（`1K`、`1⁴`、`为方` 等）
2. 或对公式类口语题启用大模型复核（配置 GRADE_LLM_*）
3. 或转写前用 `initial_prompt` 注入物理术语表（已部分生效）

## 二、"AI 充当人力"的真值方案

### 2.1 为什么需要真值

WER/CER 需要"参考转写"（音频内容的逐字真值）作为基准，通常由人工听写产出。团队无专门人力时，采用**交叉转写 + AI 校对**代理方案：

1. **交叉转写**：用更强模型（whisper-large-v3，需下载~3GB）转写作为准真值
2. **AI 校对**：基于题目语境（物理术语、句式）修正同音字/术语错误 → 真值
3. **严格口径说明**：此为**代理真值**（AI 校对非真人听写），数值为代理指标；正式交付若需严格 WER/CER，仍需人工抽检 ≥10% 样本校准

### 2.2 目录结构

```
scripts/asr_eval/
├── batch_asr.py            # 批量转写(small) → results/asr_report.json
├── asr_wer_eval.py         # WER/CER 计算(真值在 ground_truth/) → results/asr_wer_cer_report.json
├── asr_grade_impact.py     # ASR 错词对判分影响对比
├── ground_truth/           # 人工/AI 校对真值(*.txt, 与音频同名)
├── reference/              # large-v3 交叉转写(待校对)
└── results/                # small 转写 + WER/CER 报告
```

### 2.3 真值模板（可直接复用）

真值文件命名：`{音频名}.txt`（与 batch_asr 输出的 key 一致），内容为**逐字转写**：

```
# ground_truth/采访录音 1.txt
牛顿第三定律两个物体之间的作用力和反作用力大小相等方向相反作用在同一条直线上例子我推墙墙也推我
```

**校对规则**：
- 保留学生口述的**原词序、句式、语气词**（不改成标准书面语）
- 只修正**同音字/术语误识别**（侧力剂→测力计、读书→读数）
- 公式符号按发音还原（"1K"→"EK"、"二分之一"保留汉字）
- 听不清处标注 `[不清]`，不计入真值比较

### 2.4 复现命令

```bash
cd backend
# 1. 批量转写(首次需下载 small 模型)
.venv\Scripts\python ..\scripts\asr_eval\batch_asr.py "C:\Users\刘奕飞\Desktop\作答资料"

# 2. 校对真值后计算 WER/CER(已有真值时跳过 large-v3 下载)
.venv\Scripts\python ..\scripts\asr_eval\asr_wer_eval.py

# 3. ASR 错词判分影响
.venv\Scripts\python ..\scripts\asr_eval\asr_grade_impact.py
```
