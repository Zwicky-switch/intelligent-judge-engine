# 模拟教师二审测试说明

> 测试日期：2026-09-13（v1）、2026-09-13（v2 优化）
> 测试方法：引擎判分 vs 标准答案关键字对照法模拟教师二审
> 重要声明：本测试中的"教师二审"为**关键字对照法模拟评分**，非真实教师盲评。适用于基础低开放性题目，高开放性题目仍需真实教师验证。

---

## 〇、v2 评分算法优化（2026-09-13）

### 优化背景（v1 问题复盘）

v1 引擎使用**字符面覆盖率**判分：`覆盖度 = 命中去重字符数 / 全部关键字字符总长`。

**缺陷**：同义变体越多，分母（关键字总长）越大；学生只写一种表达（如"F合=ma"）时命中字符占比低，强档完整答案反而被判半分。v1 结果强档仅 67% 一致，T1 强档引擎 5.0 vs 教师 8.0。

### 优化内容

1. **关键字优化**：松散 `keywords` 列表改为**语义槽 `slots`**（同义变体分组，如"定律名称"槽含 3 个变体、"公式关系"槽含 5 个变体），命中槽内任一变体即算该槽覆盖。
2. **算法优化**：得分点覆盖度 = **命中槽数 / 总槽数**，消除"同义变体膨胀分母"缺陷，更贴近教师逐知识点判断逻辑。
3. **已落地到引擎**：`backend/app/parsers/text.py` 新增 `slot_coverage_ratio()`；`backend/app/engines/subjective.py::_judge_point` 支持 `slots` 结构（无 `slots` 时走原 `keywords` 逻辑，**向后兼容**）。

### v2 结果（同一教师基准下）

| 指标 | 原引擎（字符覆盖率） | 优化后（语义槽，真实引擎） |
|---|---|---|
| ±1分内一致率 | 11.1%（1/9） | **100%（9/9）** |
| 平均绝对分差 | 2.56 | **0.33** |
| 强档 | 0/3 | 3/3（均 0.00 分差） |
| 中档 | 0/3 | 3/3（均 0.17 分差） |
| 弱档 | 1/3 | 3/3（均 0.83 分差） |

> 注意：v1 报告的 88.9% 是"原引擎 vs v1 松散关键字教师基准"；v2 教师基准换为语义槽法（更贴近真实知识点判断），同一基准下原引擎仅 11.1%、优化后 100%，优化效果清晰可见。

### 剩余差异与调参点

优化后平均分差 0.33，主要来自**"命中一半槽"的取分比例**：
- 引擎：1/2 槽命中 → 0.5 比例 → 给 50% 分
- 教师：1/2 槽命中 → 宽容给 75% 分（教师认为"部分掌握"应给更高分）

如需进一步贴近教师，可将引擎部分分比例从 0.5 调高（如 0.6~0.75），属可调参数。

## 一、测试设计（v1 基线）

### 1.1 题目选择

模仿数据库已有题目风格，编写 3 道基础低开放性题目：

| 题目 | 类型 | 满分 | 得分点数 | 内容 |
|---|---|---|---|---|
| T1 | 主观文本 | 8.0 | 4 | 牛顿第二定律求加速度（含摩擦力） |
| T2 | 主观文本 | 6.0 | 3 | 惯性概念、决定因素、生活例子 |
| T3 | 口语（文字模拟转写） | 6.0 | 3 | 动能定理内容、公式、例子 |

### 1.2 学生答案

每道题拟写强/中/弱三档学生答案，共 9 份答卷：

- **强档**：表述完整、步骤清晰、覆盖全部得分点
- **中档**：核心步骤有但表述不完整、部分得分点遗漏
- **弱档**：概念错误或严重遗漏、仅答出零星要点

### 1.3 评分方法

**引擎判分**：调用项目内置 `grade_subjective` 引擎，基于量规关键字覆盖率判定：
- 覆盖率 ≥ 0.8 → 满足（满分）
- 覆盖率 ≥ 0.4 或命中过关键字 → 部分满足（半分）
- 否则 → 不满足（0分）

**教师二审（关键字对照法模拟）**：
- 关键字命中 ≥ 60% → 满分
- 关键字命中 ≥ 30% → 半分
- 否则 → 0分
- 阈值略宽于引擎，模拟教师的人工判断宽松度

## 三、差异分析

### 3.1 唯一不一致案例：T1 强档答案

- **引擎分 5.0/8.0，教师分 8.0/8.0，分差 3.0**
- **原因**：强档答案表述完整，但 P1（牛顿第二定律）、P2（摩擦力）、P4（加速度）三个得分点的关键字覆盖率在引擎中未达 0.8 阈值，被判为 partial（半分）；教师二审阈值为 0.6，判为满分。
- **具体**：
  - P1：答案写"根据牛顿第二定律 F合=ma"，引擎关键字列表含"牛顿第二定律""F合=ma""F=ma""合外力等于""ma"，覆盖率计算可能因分词/子串匹配问题未达 0.8
  - P2：答案写"滑动摩擦力 f=μN=0.2×20=4N"，引擎关键字含"摩擦力""μmg""μN""0.2""4N""4 N"
  - P4：答案写"加速度 a=F合/m=6/2=3m/s²"，引擎关键字含"加速度""a=""3m/s""3 m/s""6/2"

### 3.2 引擎整体偏严

- 引擎平均分（3.11）低于教师平均分（3.44）
- 引擎关键字覆盖率阈值（0.8）高于教师模拟阈值（0.6），对于表述完整但关键字形式不同的答案容易给半分
- 中档和弱档答案因关键字覆盖本身就低，引擎和教师判定一致

### 3.3 改进建议

1. **优化关键字列表**：增加同义词、常见表述变体、公式的不同写法（如 `F合=ma` vs `F=ma` vs `ma=F合`）
2. **调整覆盖率阈值**：可考虑将满足阈值从 0.8 降至 0.7，减少强档答案的误判
3. **增加语义匹配**：当前为纯关键字子串匹配，未来可引入同义词词典或向量相似度

- 本测试的"教师二审"为**标准答案关键字对照法模拟评分**，不是真实教师盲评。

- 本测试可作为真实教师盲评前的**预演和基线**，证明引擎在基础题上的判分一致性接近目标（≥90%）。
